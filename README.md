# ⚽ Tashkela

**Tashkela** is a modern sports web application landing page designed to help users easily book sports fields, create teams, and participate in exciting tournaments.

## 📌 About the Project

Tashkela provides a clean, modern, and responsive user interface focused on simplicity and a smooth user experience across different screen sizes.

## ✨ Features

- 🏟️ Easy and fast field booking
- ⚽ Match and tournament management
- 💳 Secure and flexible payment
- 🔔 Match notifications and reminders
- 👥 User testimonials
- ❓ Frequently Asked Questions (FAQ)
- 📱 App download section
- 📞 Contact form
- 📱 Fully responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Font Awesome
- Bootstrap Icons
- Google Fonts – Tajawal

## 📱 Website Sections

### 🏠 Home

A hero section introducing the application with a short description and app download buttons.

### ⭐ Why Choose Us?

Highlights the main features and benefits of the application.

### ⚽ How Does It Work?

A step-by-step explanation of how users can create an account, find fields, choose a suitable time, make a payment, and enjoy their game.

### 💬 User Testimonials

An interactive carousel displaying feedback from different users.

### ❓ FAQ

A frequently asked questions section built using Bootstrap Accordion.

### 📲 Download the App

A dedicated section encouraging users to download the application.

### 📞 Contact Us

A contact section with a form and contact information.

## 📱 Responsive Design

The website is responsive and optimized for:

- 💻 Desktop
- 📱 Mobile
- 📟 Tablet

CSS media queries are used to adapt the layout to different screen sizes.

## 🚀 How to Run

No special installation is required.

Simply open:

```text
index.html
```

in your browser.

You can also use **Live Server** in Visual Studio Code for a better development experience.
